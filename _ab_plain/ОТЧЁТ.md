# Кузница 2 x 2 для mapgen2 — что сделано и чем проверено

**Сделано.** Деревенская кузница пятном 2 x 2 клетки (X — длинная сторона, воротца в `+Y`): каменный цоколь, обмазанные стены с деревянным каркасом, широкие воротца из двух створок с железом, одно окно на торце, двускатная соломенная кровля 47°, каменная труба горна со сдвигом от конька, навес над воротцами, двор — кадка закалки, поленница, мох у цоколя, кожаный фартук кузнеца. Генератор — `tools/building.py`: чистый Python без `bpy`, `build(variant=None)` отдаёт список деталей `dict(name, family, verts, faces)`; варианты `a` (базовый), `b` (крыльцо на столбах), `c` (крутая кровля, узкие воротца).

**Приёмы.** Цоколь — ядро + блоки со швом 0.025 и наклоном ±2.5°; стены — усечённая призма (верх шире низа); каркас — нижняя/верхняя обвязка, угловые и промежуточные стойки, раскосы ровно 45°, каркас щипца; кровля — тело скатов + 5 пластов соломы на скат с оборванным краем, гребень, лобовые доски, прижимные жерди; воротца — тёмное полотно (`leather`) + светлые доски (`trunk`) + кованые раскосы, жиковины и кольцо (`iron`). Каждая деталь — «труба» между двумя кольцами, поэтому замкнутость и наружные нормали выходят сами; тон фасета считается по нормали (`tools/tone.py`, 7 семейств x 3 тона), базовые цвета материалов взяты из калибровки соседнего дома (`pal_cal.json`) — деревня сходится по цвету.

**Чем проверял.**
- `python3 tools/report.py` — 1424 трис (бюджет 300..1500), габарит 1.960 x 1.943 x 2.701, уклон 47°, свесы 14.3% по скату и 7.6% по торцу, пятно внутри ±1.0, все детали замкнуты, объём > 0 (нормали наружу), вырожденных граней нет, минимальная деталь 0.026 (канон ≥ 0.02), каркас из-под кровли не торчит.
- `python3 tools/checks.py` → `out/checks.txt`: свой софт-рендер с z-буфером дал **0 пикселей изнанки** на 15 видах (iso/front/back/left/right x 3 варианта); стиль-гейт `scripts/audit.py --kind building` на **13 кадрах** (3 варианта x 4 поворота + @4x) — **0 FAIL, 0 WARN**: палитра 99.6..99.7%, крупных фасетов 9..10 (67..78% площади), контур 1.0 px, тень 0.98..1.00 ширины силуэта при h/w 0.17.
- Сборка и кадры — в **живом Blender** через сокет 9876: `python3 tools/blmcp.py run tools/build_live.py` (своя сцена `ab_plain`, свой префикс `abp_`, `read_factory_settings` не звался, файл заказчика не сохранялся; окно переключено на мою сцену, чтобы модель была видна). Плюс выгрузка `out/smithy_a.obj`.

**Что осталось неидеальным.** Створки ворот на 96 ppu читаются тёмным пятном: доски и полотно различаются тоном слабо, вытянуло только разделение семейств `leather`/`trunk`; вершин 948 при ориентире класса 200..800 из `palette.json` (деталей много, склейка сэкономила бы вершины, но не треугольники); тень — плоский эллипс в экранных пикселях по канону поста, а не расчёт по солнцу, и на глаз она чуть «пухлая». Живую сессию я не сохранял в `.blend` — отдаю генератор, кадры и OBJ.
