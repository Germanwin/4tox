# _ab_skill — деревенская КУЗНИЦА 2 × 2 для 4tox/mapgen2

Собрано по скиллу `4tox-building-forge`.  Сцена Blender `abskill`, префикс имён
`abs_`, кадр 96 ppu (изометрия 2:1).

**Постройка.** Каменный цоколь, стены-обмазка в деревянном каркасе (обвязки,
стойки, 7 раскосов), широкие воротца 1.00 × 0.95 из двух створок с оковкой,
одно окно 0.28 на торце −X, двускатная солома 45° (4 пласта), свесы 12.5% / 5.7%,
каменная труба горна смещена от конька (−0.40, +0.28), навес над воротцами и
козырёк над окном, двор: кадка для закалки и стопка заготовок.
**Числа:** 1026 трис, 110 деталей, габарит 1.97 × 1.90 × 2.67, пятно 2 × 2.

**Чем отличается от соседей.** Дом жителя (`villager_house`) — 3 × 2, сруб и
два окна; кузница — 2 × 2, фахверк с раскосами, воротца вместо двери, труба
горна на скате и навесы над входами. Канон пропорций тот же (общий `canon.py`
класса `building`, без своих диапазонов в `SPEC`).

**Что проверено.** `canon.py` → «ИТОГ: ПРИНЯТО» (0 замечаний по нормалям);
`xray.py probe --full` → изнанок ≤3 px на деталь и 0 совпадающих плоскостей;
живая сборка в Blender 5.2 (4 поворота + кадр 4×); стиль-гейт `audit.py` на 1×
и 4× → «ОК (0 FAIL, 0 WARN)» во всех пяти прогонах, палитра 99.2..99.3%. Подробности — `out/report.txt`
и `ОТЧЁТ.md`.

## Инструменты (копии из скилла, можно править под эту постройку)

| файл | что делает |
|---|---|
| `tools/building.py` | ГЕОМЕТРИЯ: чистый Python, ярусы и раскладка. Главный файл. |
| `tools/forge.py` | примитивы, отсев невидимых фасетов, триангуляция, палитра |
| `tools/xray.py` | софт-рендер и детектор дефектов (изнанки, зазоры, z-fighting) |
| `tools/canon.py` | приёмка по канону: ярусы, габарит, уклон, свесы, бюджет, нормали |
| `tools/blender_live.py` | материалы, свет, камера, рендер, экспорт (внутри Blender) |
| `tools/build_live.py` | точка входа сборки в живом Blender |
| `tools/mcp.py` | клиент сокета аддона blender-mcp (снаружи Blender) |

## Порядок работы

```bash
PY=/Users/hermmoment/.dsh/profiles/desktop/node_modules/dsh-blender/.venv/bin/python
PY3=/Users/hermmoment/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3

$PY3 tools/canon.py --gen tools/building.py        # числа против канона
$PY3 tools/xray.py probe --gen tools/building.py --full   # дефекты, 32 ракурса
$PY  tools/mcp.py run tools/build_live.py          # сборка в УЖЕ ЗАПУЩЕННОМ Blender
$PY  tools/mcp.py shot renders/live.png            # посмотреть вьюпорт
```
