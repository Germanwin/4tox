# 4tox

Изометрическая игра: остров, деревня вокруг ратуши, лесоруб и житель. Карта
рисуется на канвасе, спрайты — низкополигональные модели из Blender.

Игра открывается как страница: **`mapgen2/index.html`** (работает и по
`file://`, и по http). Панель генератора карт — кнопка **⚙** или клавиша **`**.

## Карта репозитория

```
4tox/
├── docs/           правила: раскладка (STRUCTURE.md) и поток ассета (PIPELINE.md)
├── mapgen2/        ИГРА: index.html, js/, css/, assets/, tools/
├── art/            МОДЕЛИ: buildings/, characters/, props/, fx/
├── research/       РАЗБОРЫ чужого и своего: hero/, coc_house/
└── experiments/    ОПЫТЫ, которые не идут в игру: ab_plain/, ab_skill/, forge_demo/
```

Четыре верхних папки — это четыре разных ответа на вопрос «что это такое».
Новое кладётся в ту, что отвечает на вопрос, а не в корень.

| Разобраться в конкретной постройке | README внутри её папки в `art/` |

## Что уже стоит в игре

| Слой | Атлас | Откуда модель |
|---|---|---|
| Деревья, камни, кусты | `mapgen2/assets/sprites/` | унаследован; исходных моделей нет |
| Ратуша, 3 варианта × 4 поворота | `mapgen2/assets/townhall/` | [art/buildings/townhall](art/buildings/townhall/README.md) |
| Гребни волн | `mapgen2/assets/waves/` | [art/fx/waves](art/fx/waves/README.md) |
| Лесоруб (герой) | `mapgen2/assets/hero/` | унаследован; исходных моделей нет |

Собраны, но в игру **ещё не подключены** (лежат готовыми атласами): дом жителя
`assets/house/`, хижина `assets/hut/`, лагерь лесоруба `assets/lumbercamp/`.

## Правила, которые здесь держат порядок

1. **Один артефакт — одно место.** Модель живёт в `art/`, игра её не читает
   напрямую: между ними стоит упаковщик и `mapgen2/assets/`.
2. **Корень репозитория не свалка.** В корне только `docs/`, `mapgen2/`,
   `art/`, `research/`, `experiments/` и два файла правил.
3. **Абсолютных путей внутрь репозитория нет.** Скрипт считает пути от
   `__file__`; проект на `art/<группа>/<имя>` знает, что до корня три уровня.
4. **Правила игнора — только в корневом `.gitignore`.**
5. **Одноразовое не живёт рядом с боевым.** Проба скилла — в `experiments/`,
   разбор — в `research/`.

Подробности и обоснования — [docs/STRUCTURE.md](docs/STRUCTURE.md).
