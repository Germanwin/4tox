# Замер 600 жителей на целевом ноутбуке: сборка и чеклист

Дата: 2026-11-02. Согласовано с заказчиком: целевое железо заменяется
«M4 + запас»; этот файл — то, что нужно сделать на Windows-ноутбуке 2020+
с интегрированной графикой, чтобы число было настоящим.

## Что уже измерено (M4, 1440×900, z40, vsync off)

`tests/perf_world.gd`: 600 жителей, 2687 видимых объектов природы, 3 дома.

| сцена | кадр | fps | CPU отрисовки слоя |
|---|---|---|---|
| камера стоит | 1.86 мс | 537 | 0.23 мс |
| камера едет | 4.03 мс | 248 | 2.34 мс |

Порог заказчика — 60 fps (16.7 мс) на ноутбуке 2020+. Запас на M4 — 8×
стоя; на интегрированной графике Godot 4 Compatibility обычно в 2–4 раза
медленнее на пиксель, то есть ожидаемо 100–250 fps. Проверить.

## Сборка для замера

1. Godot 4.7.2 (тот же, что в репозитории) на Windows-машине.
2. Из корня репозитория:
   ```
   cd godot
   Godot --headless --path . --import
   Godot --headless --path . --export-release "Windows Desktop" ../4tox-perf.exe
   ```
   (пресет экспорта — `export_presets.cfg`, если его нет, добавить
   «Windows Desktop» с renderer = Compatibility).
3. Положить рядом `tests/fixtures/` (world.json, scene_*.json, frame.bin) —
   `perf_world.gd` читает их через `res://tests/fixtures`.
   Проще: не собирать exe, а поставить Godot 4.7.2 и запустить из
   репозитория — замер тот же:
   ```
   Godot --path . -s res://tests/perf_world.gd
   Godot --path . -s res://tests/perf_world.gd -- pan
   ```
