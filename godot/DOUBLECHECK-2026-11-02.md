Промежуточные красные прогоны, на которых нашлись настоящие ошибки (а не
подгонка порога):

1. Маска газона была инвертирована (`Phi` с неверным знаком) — 3.3 %.
2. Маска размывалась НАРУЖУ, а браузер режет размытие клипом полигона —
   край должен быть жёстким, размытие внутрь. 0.578 % → 0.057 % после
   исправления и включения бахромы.
3. Знак фазы плитки измерен пробой canvas-паттерна; с «плюсом» интерьер
   расходился на 13.8/255 в среднем, с «минусом» — 0.06/255.
4. Песок: дизеринг рисовался только для клеток полосы, внутренняя кромка не
   сходилась; после включения клеток с distWater ≤ 3.1 — 0.83 % → 0.25 %.
5. Батчинг: `draw_set_transform` не снимался перед постройкой — лагерь
   уезжал за экран (full_z64 0.512 %); поймано пиксельным гейтом.
6. Отсечение жителей по кадру конфликтовало с мировым мешем (уехавший
   житель не попадал в меш) — убрано; перф 2.17 мс.
