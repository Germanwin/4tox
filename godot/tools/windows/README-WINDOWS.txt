4tox — изометрическая деревня
Windows x64 · версия 0.2.0
================================

ЗАПУСК
------
Двойной клик по 4tox.exe (или по ярлыку «4tox» в меню Пуск / на рабочем столе).
Требуется Windows 10 или 11, 64-битная.

Ничего доустанавливать не нужно. Рядом с игрой лежит папка server:
  server\node.exe              — Node.js, который поднимает локальный сервер;
  server\game\server\server.js — сам сервер (мир считает он);
  server\game\shared\          — общий протокол;
  server\mapgen2\js\           — генератор острова и правила.
Игра сама находит node.exe, выбирает свободный порт 8790–8899 и запускает
сервер. Терминал, Node.js из интернета и настройка порта не нужны.

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ
--------------------------
Сборка не подписана платным сертификатом, поэтому SmartScreen может сказать
«Windows защитила ваш компьютер». Это не вирус: нажмите «Подробнее» →
«Выполнить в любом случае». Если антивирус удалил файл — распакуйте
portable-архив в отдельную папку и запустите 4tox.exe оттуда.

УПРАВЛЕНИЕ
----------
Панорама            ЛКМ/СКМ с перетаскиванием, WASD, стрелки
Зум                 колесо мыши (к курсору)
Выбрать             клик по постройке или жителю
Правка              удержать ЛКМ 0,5 с или двойной клик
Стройка             «Стройка» → карточка → клик по карте
Серия домов          «Серия» → клик по концу → «Построить»
Найм / тренировка   клик по лагерю лесоруба / казарме
Войска              O; приказ — клик по карте
Сеть                меню «Сеть» → «Создать игру» / «Войти по коду»
Деревня             T
Общий план          V
К жителю / следить  H / C
Новый остров        N
Меню (мир не стоит) Esc
Отмена              ПКМ / Esc

ГДЕ ЛЕЖАТ ДАННЫЕ
----------------
Сохранения, настройки и логи:
  %APPDATA%\Godot\app_userdata\4tox
Лог локального сервера:
  %APPDATA%\Godot\app_userdata\4tox\logs\server.log
Если игра пишет «не удалось запустить сервер» — сначала смотрите этот лог.

УДАЛЕНИЕ
--------
Параметры Windows → Приложения → 4tox → Удалить,
либо Uninstall.exe в папке игры. Установщик спросит, удалять ли сохранения.

ПЕРЕНОСИМАЯ ВЕРСИЯ
------------------
Если установщик не нужен, распакуйте 4tox-0.2.0-windows-portable.zip в любую
папку и запустите 4tox.exe. Все файлы, включая server и node.exe, уже внутри.
