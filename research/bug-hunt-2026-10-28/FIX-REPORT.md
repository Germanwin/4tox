## Исправлено в этой итерации

### Безопасность и сервер

- **C-04.** `serveStatic`: путь нормализуется ПОСЛЕ `decodeURIComponent`,
  запрещены `..`/`\0`, проверка каталога идёт по `path.resolve`. Живой
  `GET /game/%2e%2e/AGENTS.md` теперь 404; `/game/` — 200.
- **C-05.** Закрыты `/game/server/` и `/game/tools/` в статике; `lobby.json`
  с токенами больше не отдаётся (тест 404).
- **C-06.** `persistence.readJournal` усекает оборванный хвост до последней
  целой записи; второй рестарт больше не падает `journal_checksum`.
- **B-02.** `buildPrice` — только свои ключи; `buildOne`/`buildLine`
  проверяют `Buildings.TYPES`. `"constructor"` отклоняется, казна остаётся
  числом, комната не падает.
- **C-03.** `spritesFor` — `hasOwnProperty` для `buildingSets`/`ruinSets`.
- **M-12.** `MAX_LOBBIES` (256) в `POST /api/lobby`.
- **M-29.** `/api/command-state` отбрасывает чужие `commandId` (не начинаются
  с instance игрока).
- **M-10.** `town_gone` проверяется для ВСЕХ команд, а не только `build`.

### Мир и деревня

- **C-02.** `villageAt` принимает `avoid`; `startMultiCore` накапливает
  постройки, бот получает `playerList`. Пересечений 0 на `mp-14`/`scan-13`.
- **M-14.** `placeAll` учитывает `avoid`/`world._buildings`; повторная
  «Все три» не кладёт те же пятна.
- **M-15.** `WorldGen.hashWorld` — отпечаток тайлов и объектов, считается при
  генерации (до деревни); `Replication` и `Serialize.apply` сверяют seed,
  size и хеш; чужой мир не применяется молча.
- **M-09 (завал).** Завал проходим (`blockedMap`), застраиваем
  (`canPlace`), новая постройка убирает руину из списка.
- **M-11 (дверь).** `canPlace` отвергает дверь в воду/за край.
- **M-07 (дом).** Снос дома обнуляет `v.home` жильцов и ставит якорь.
- **M-10 (лагерь).** Завал военного лагеря можно снести.
- **M-12 (вариант).** Военный лагерь без варианта получает `x`; чужой
  вариант — `bad_variant`.

### Жители, бой, экономика

- **M-08.** `standCells` не отдаёт клетку, где стоит/идёт другой рабочий;
  на сиде `chop-6` — 0 кадров «двое в одной клетке» (было 479).
- **M-19.** `deliveredSeen` ключуется по id жителя, а не по индексу; после
  смерти нет ложной сдачи «+0».
- **M-02 (метка).** `killVillager` снимает `tree.mark`.
- **M-04 (замах).** `attackT` ставится при входе в дальность; замер —
  0.383 с вместо 0.016 с.
- **M-06 (журнал).** Повтор атаки после вытеснения создаёт новую запись.
- **M-26.** Волновой слой не строится, если даже 12 px гребня меньше порога.
- **M-21.** Хэш волн — логические сдвиги (`>>>`): 45 %/30 % вместо 90 %/60 %.

### Интерфейс

- **M-03.** «Двигать» обрабатывается до сетевой ветки; `place` проверяет
  `e.valid`.
- **M-04.** «Новый остров» из сети — `Lobby.enterGame`, меню не остаётся.
- **M-05.** Enter на кнопке/карточке активирует её, а не запускает игру;
  стрелки пропускают скрытую 48.
- **M-06.** Журнал перерисовывается по подписи всех 8 событий.
- **M-13.** Панель найма закрывает ящик/«Войска»/меню построек.
- **M-14.** Список журнала прокручивается (`pointer-events:auto`).
- **M-15.** T молчит за доской «Меню»/итогом.
- **M-22.** Миникарта пересобирается после рубки в соло/генераторе.
- **M-23.** Сохранённый `tier='low'` включает экономию целиком (кнопка,
  fpsCap, волны), а не половину.
- **M-24.** `Quality.coarse()` — только `(pointer: coarse)`, тач-ноутбук
  больше не «телефон».
- **M-25.** Экспорт PNG: сдвиг на наземный контур, завалы, вся галька.
- **CSS.** Карточка размера поднимается (`backwards`), бейдж не накрывает
  журнал на 360 px.
- **Генератор.** «Ратуши» считает ратуши, мёртвая полоса «Лесоруб» удалена.
- **README.** Три постройки на старте, а не четыре.

## Осталось / требует решения

- **minor 9 (частично):** завал теперь проходим и застраиваем, но отдельного
  визуального «сминания» руины (эффекта) нет — только удаление из списка.
- **minor 27:** `MIN_ZOOM = 3` не даёт вписать 192/256 на телефоне. Менять
  предел — значит пересматривать контракт `fitIsland` и приёмку `game.js`;
  без решения заказчика не трогал.
- **minor 28:** checkpoint каждые 2 с на 192-й карте ≈1.5 МБ/с. Это
  осознанный компромисс «потерять ≤2 с»; менять частоту без замера диска на
  VPS не стал.
- **cosmetic 1:** `game/tools/http.js` — старый host-authority тест, падает
  на текущем protocol 4 (ждёт `/api/snapshot` 200 и `cmdProto=2`). Игру не
  проверяет; переписывать приёмочный файл целиком — отдельная задача.
- **cosmetic 2:** второй обработчик `/api/snapshot` в `server.js` недостижим
  (мёртвый код после безусловного 409). Удаление — механическое, но
  затрагивает ~100 строк; оставлено до отдельной чистки.
- **Открытый вопрос:** «против деревни» — враг по-прежнему не нападает сам.
  Это может быть задумано (штурм игрока); менять ИИ без решения не стал.
